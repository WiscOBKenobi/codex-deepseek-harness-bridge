## 对接检查

官方 headless 的入口、JSON 参数、会话继续参数、补丁行 ID、工具限制、进度事件和 Windows ACL 公开导出仍兼容。新版会话上传开关改用动态配置值，桥接传入 false 的方式仍支持；新增统一遥测服务后，实际装载检查仍返回分享关闭。

上游将网页的自动化任务插件移到可选 bundle。桥接的长期任务由自身后台队列与监督负责，未依赖该插件；本项目仍不提供唤醒已结束 Codex 回合的服务。原 Windows 新任务初始化继续沿用已授权的局部权限准备与官方沙箱，没有关闭沙箱。

## 验证中修正的问题

测试夹具原先先删除临时目录，再关闭管理器，可能与尚未完成的异步落盘竞争，出现 Windows ENOTEMPTY。已改为在删除前等待所有所属管理器关闭，包括重新创建的实例；产品 shutdown 无需修改。

真实验证脚本原先按固定查询次数结束。进度事件频繁时，查询快速返回，次数用尽并不表示任务超时。已改为按验证时间截止等待，并沿用原检查点取回已完成任务，未为此重复提交付费任务。
