## Verification fixes

Temporary test cleanup previously deleted directories before all task-manager writes stopped, causing a possible Windows ENOTEMPTY race. Fixtures now wait for every owned manager, including recovered instances, before deleting test directories. Product shutdown needed no change.

Live verification previously stopped after a fixed number of queries. Frequent events made queries return immediately, exhausting the count while a task was still running. Scripts now use an elapsed-time deadline and retained checkpoints, avoiding duplicate paid submissions.
