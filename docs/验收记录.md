## 已交付能力

连接程序提供七个 MCP 工具、独立后台队列、两种执行模式、持久化结果、续办与取消、监督心跳、停滞提示、独立验收记录、可选中文面板，以及四个 Windows 双击入口。Codex 保留客户端所选模型，DeepSeek 通过官方 Harness headless 执行委派任务。

本机已获授权启用 agent 编码模式；可分发的配置模板仍以 files 为默认，原生编码与 Windows 目录初始化均需单独显式启用。运行时长和工具次数可设为 0，任务正常完成后结束；程序不会无限重试失败任务。

## 真实任务与权限修复

真实调用使用 Harness 已保存的凭据，以及原有 `deepseek-official / deepseek-flash / max` 配置。MCP 客户端通过官方 SDK 连接本项目的 stdio 服务，本项目再启动官方 headless；没有绕开 Harness 直接调用模型。

files 测试先读取含随机标识的输入，生成 count=5、sum=28 的结果，再继续原会话将状态改为 verified。Codex 读取实际磁盘文件并核对标识、数量、总和及修改结果。

agent 首次命令执行暴露出 Windows 目录权限问题，当时未将失败误记为通过。经明确授权，仅给测试 workspace 原所有者补非继承 WRITE_OWNER，让官方沙箱初始化根权限；旧子目录保留备份，新建目录后按字节复制文件并逐一校验哈希。随后先通过无模型的目录内写入、目录外拒绝检查，再继续原模型会话完成测试。最终读取了源码和测试代码，并独立执行其 6 项测试。

新任务的可选修复按“空 workspace → 根权限准备 → 官方 ACL 初始化 → 创建 input/output → 复制输入”执行，不递归修改已有任务。模拟测试覆盖这一顺序与失败路径。经用户另行明确授权，已保存本机自动初始化设置，并使用全新的空目录直接调用实际 prepareWorkspace：初始化及输入复制一次成功，随后官方沙箱原生命令内写成功、外写被拒绝，外部校验文件未变，退出码为 0，全程模型请求为 0。系统权限命令显式从 Windows PowerShell 自带模块加载，避免其他 PowerShell 版本的模块路径影响。

实际任务编号、会话编号、运行检查点、原始输入及产物仅保留在本机忽略目录 `.bridge`，不放进公开源码或下载包。真实测试脚本会复用已有检查点，避免重复付费；明确创建新真实测试会消耗 API 额度。

## 验证范围与限制

- 已验证官方 MCP 协议的实际调用链；新增项目配置不能保证热加载到已有 Codex 回合。在本项目的新任务中加载 MCP，并按客户端提示确认项目信任。
- 浏览器验证覆盖本机 Edge，未覆盖所有浏览器和 Windows 版本。图形化安装器的目录选择、缺失依赖时的交互安装未做完整人工操作验收。
- agent 已实测文件编辑与原生命令执行；没有额外用付费任务验证依赖安装、浏览器、搜索或子代理插件。这些能力依赖所装 Harness 及其配置。
- Windows 原生沙箱提供部分隔离；不宣称完全限制读取和网络。后台权限请求无人应答时拒绝，不自动批准。
- 未进行连续 24 小时或更长运行的实机耐久测试。无限时配置、分段计时器、进度与心跳分离、停滞提示、取消和异常恢复已有自动化回归。
- 心跳与本地等待不产生模型请求；Codex 解读状态与做决定仍消耗自身用量，DeepSeek 实际执行独立计费。后台服务不会主动唤醒已结束的 Codex 回合，电脑关机或休眠也无法持续执行。
- output 大小限制是交付收集限制，不是 agent 工作目录的磁盘配额；运行时长和工具次数也不是精确金额上限。
- 验收对应文件 SHA-256 快照；产物改变时返回 reviewStale，要求重新核对。任务执行完成不等于已通过独立验收。
- 日志不保留原始模型思考、原始 stderr 或 API Key；任务指令、复制输入、结果和经过限制的进度信息保存在本机 `.bridge`，不应随源码分享。
